# 口袋地球 · 欧洲、亚洲与北非原型

一个可直接游玩的 Three.js 最小原型。世界采用真实国家轮廓打底、连续程序化地表覆盖的玩具地图风格。

世界名胜、自然奇观与历史现场的扩充清单见 [WORLD_SITES_ROADMAP.md](./WORLD_SITES_ROADMAP.md)。

在线试玩：<https://softxuep-dotcom.github.io/WorldRide/>

- 全球 50m 级国家轮廓已经生成。
- 欧洲：葡萄牙、西班牙、法国、英国、德国、意大利、希腊、荷兰、瑞士、奥地利、波兰和挪威。
- 亚洲及欧亚连接：土耳其、中国、日本、韩国、印度、泰国、越南、印度尼西亚、俄罗斯、伊朗、沙特阿拉伯、巴基斯坦和蒙古国。
- 北非：摩洛哥、阿尔及利亚、突尼斯和埃及。
- 以上二十九个国家拥有连续地表、独立内容锚点、国家详情和护照印章；国家数量不与打卡点数量绑定。
- 世界中设置 38 个精选手机打卡点，以及 27 个可在驾驶途中自动发现的地区特产。
- 罗盘默认指向最近的未收集名胜，也可以从三个最近候选中选择心愿目的地。
- 新旅程先显示驾驶画面，首次有效移动后罗盘才淡入；距离使用近、中、远三个档位。
- 低空鸟群会被车辆惊起，农田会在经过时泛起波纹；这些环境反应不进入收藏。
- 护照集中显示国家、名胜和地区特产进度，并可打开 38 格明信片收藏册。
- 国家、名胜和特产达到阶段性数量时会播放里程碑庆祝。
- 详细地表使用草叶、农田、沙纹和岩纹等程序化微纹理；草地、热带丛林、山地与沙漠拥有不同的颜色、植被轮廓和装饰性地貌。
- 其他国家暂时作为轻量底图，之后可以逐批增加内容。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 多语言

当前内置简体中文（`zh-CN`）和英文（`en`），按以下顺序选择初始语言：

1. URL 参数，例如 `?lang=en`
2. 用户上次在页面中的选择
3. 浏览器首选语言
4. 英文兜底

运行中可用底部“设置”里的语言选择器切换。稳定的国家和景点 ID、坐标、颜色等结构数据仍放在 `src/game/data.ts`；界面与内容翻译放在 `src/i18n/locales/`，不会影响存档、地理匹配或游戏逻辑。

新增语言时：

1. 复制 `src/i18n/locales/en.ts` 创建新语言包，并补齐界面文案。
2. 在 `src/i18n/index.ts` 导入语言包并加入 `localeRegistry`。
3. 运行 `npm run build`；类型检查会验证英文国家和景点内容是否覆盖全部稳定 ID。

语言包可逐步翻译；未提供的内容会回退到源数据。需要在 HTML 中增加静态文案时，可使用 `data-i18n="消息键"` 或 `data-i18n-attr="aria-label:消息键"`。

## 操作

- 桌面：`WASD` 或方向键移动，滚轮缩放，`M` 查看全球地图，靠近奇观后按空格或 `E` 手机打卡。
- 手机：在画面任意位置按住并拖动移动，靠近发光奇观后点击地点卡。
- 驶入水面会自动变成小船，上岸后自动恢复汽车。
- 点击屏幕上方罗盘选择想去的名胜。
- 底部操作坞持续提供设置、知识挑战和护照；护照中可查看进度并翻看明信片册。
- 点击顶部地图按钮，可以在局部旅行和全球俯视之间切换。

默认从法国马赛出发。出生时不会播放“抵达法国”，之后跨入其他国家会显示非阻断提示。

内容原则：国家负责抵达，奇观负责打卡，照片负责收藏。地理负责好玩，名胜负责吸引。

全球底图使用 `world-atlas` 的 50m 级 TopoJSON 数据，国家发现、车船切换、3D 国家块、装饰范围和迷你地图统一以该 atlas 为唯一几何来源；`data.ts` 只保存旗帜、介绍、城市和地貌类型等国家内容。运行时不请求外部地图服务。东西方向已首尾循环，南北方向仍以原型边界收束，适合 Poki 的自包含构建要求。
