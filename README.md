# 口袋地球 · 欧洲、亚洲与北非原型

一个可直接游玩的 Three.js 最小原型。世界采用真实国家轮廓打底、方块地块拼盘覆盖的玩具地图风格。

在线试玩：<https://softxuep-dotcom.github.io/WorldRide/>

- 全球低精度国家轮廓已经生成。
- 欧洲：葡萄牙、西班牙、法国、英国、德国、意大利和希腊。
- 亚洲及欧亚连接：土耳其、中国、日本、韩国、印度、泰国、越南和印度尼西亚。
- 北非：摩洛哥、阿尔及利亚、突尼斯和埃及。
- 以上十九个国家拥有地块、城市、地标和明信片内容。
- 其他国家暂时作为轻量底图，之后可以逐批增加内容。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 桌面：`WASD` 或方向键移动，滚轮缩放，`M` 查看全球地图，空格或 `E` 拍照。
- 手机：左下角摇杆移动，靠近发光地标后点击拍照按钮。
- 驶入水面会自动变成小船，上岸后自动恢复汽车。
- 点击右下角“护照”查看已经发现的国家。
- 点击右上角世界缩略图，可以在局部旅行和全球俯视之间切换。

默认从西班牙南部加的斯附近出发。向南可以穿过直布罗陀海峡进入摩洛哥，向西和向北则可寻找葡萄牙与法国。

内容原则：地理负责好玩，名胜负责吸引，明信片负责记住。

全球底图使用 `world-atlas` 的 110m 级 TopoJSON 数据，运行时不请求外部地图服务，适合 Poki 的自包含构建要求。
