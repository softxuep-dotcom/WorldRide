# 口袋地球 · 欧洲、亚洲与北非原型

一个可直接游玩的 Three.js 最小原型。世界采用真实国家轮廓打底、连续程序化地表覆盖的玩具地图风格。

世界名胜、自然奇观与历史现场的扩充清单见 [WORLD_SITES_ROADMAP.md](./WORLD_SITES_ROADMAP.md)。

在线试玩：<https://softxuep-dotcom.github.io/WorldRide/>

- 全球 50m 级国家轮廓已经生成。
- 欧洲：葡萄牙、西班牙、法国、英国、德国、意大利、希腊、荷兰、瑞士、奥地利、波兰和挪威。
- 亚洲及欧亚连接：土耳其、中国、日本、韩国、印度、泰国、越南、印度尼西亚、俄罗斯、伊朗、沙特阿拉伯、巴基斯坦和蒙古国。
- 北非：摩洛哥、阿尔及利亚、突尼斯和埃及。
- 以上二十九个国家拥有连续地表、独立内容锚点、抵达演出和护照印章；国家数量不与打卡点数量绑定。
- 首批设置十四个精选手机打卡点，只放在值得停留的奇观、名胜或自然景观，之后可以独立扩充。
- 详细地表使用草叶、农田、沙纹和岩纹等程序化微纹理；草地、热带丛林、山地与沙漠拥有不同的颜色、植被轮廓和装饰性地貌。
- 其他国家暂时作为轻量底图，之后可以逐批增加内容。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 桌面：`WASD` 或方向键移动，滚轮缩放，`M` 查看全球地图，靠近奇观后按空格或 `E` 手机打卡。
- 手机：左下角摇杆移动，靠近发光奇观后点击手机打卡按钮。
- 驶入水面会自动变成小船，上岸后自动恢复汽车。
- 点击右下角“护照”查看已经发现的国家。
- 点击右上角世界缩略图，可以在局部旅行和全球俯视之间切换。

默认从西班牙南部加的斯附近出发。向南可以穿过直布罗陀海峡进入摩洛哥，向西和向北则可寻找葡萄牙与法国。

内容原则：国家负责抵达，奇观负责打卡，照片负责收藏。地理负责好玩，名胜负责吸引。

全球底图使用 `world-atlas` 的 50m 级 TopoJSON 数据，国家发现、车船切换、3D 国家块、装饰范围和迷你地图统一以该 atlas 为唯一几何来源；`data.ts` 只保存旗帜、介绍、城市和地貌类型等国家内容。运行时不请求外部地图服务。东西方向已首尾循环，南北方向仍以原型边界收束，适合 Poki 的自包含构建要求。
